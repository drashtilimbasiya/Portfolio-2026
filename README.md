# Drashti Limbasiya – Developer Portfolio

## View it
**Double-click `index.html`.** It opens in Chrome (or any browser) directly from the folder.
No npm, terminal, localhost or server is needed. Everything it uses is inside this folder.

(The page loads the Inter / JetBrains Mono fonts from Google Fonts when you are online; offline it falls back to system fonts.)

## Folder structure
```
index.html              open this
assets/app.js, app.css  compiled site (plain script, works from file://)
favicon.svg
projects/               original screenshots: electrohub/, garage/ (+ sample bill PDF), parking/
certificates/originals/ the six original certificates, untouched
certificates/previews/  renderings used only for on-page viewing
resume/                 Drashti_Limbasiya_Resume.pdf (original) + page previews
source/                 editable React + Vite source (for later changes / deployment)
```

## Editing later
The readable source is in `source/` (data in `source/src/data/`). To change content, edit there and rebuild
`assets/app.js` + `assets/app.css`; ask Claude to do this and re-package it for you.
GitHub / Vercel hosting is intentionally not set up yet.
